About Ambient AI Scribe

This website connects to the FastAPI backend and helps clinicians convert recorded conversations into structured clinical documentation.

  • Upload audio to create a transcript
  • Generate a SOAP note
  • Receive ICD code recommendations
  • Save encounters for each patient

Run the backend with uvicorn main:app --reload --host 0.0.0.0 --port 8000 and open http://localhost:8000.
